# Поток

Веб-приложение для анализа транспортных потоков по изображениям. «Поток» распознаёт легковые автомобили, автобусы и грузовики на загруженном кадре, сохраняет результаты в SQLite и предоставляет API и веб-панель для работы с данными камер.

## Возможности

- Загрузка изображения через веб-интерфейс или API, включая выбор файла и перетаскивание в браузере.
- Подсчёт автомобилей, автобусов и грузовиков моделью YOLOv8n с COCO-классами.
- Просмотр результата текущего распознавания и последних записей.
- Сохранение метрик камеры: идентификатора, количества транспортных средств, средней скорости и уровня загруженности, а также фотографии.
- Просмотр архива метрик с ссылками на сохранённые фотографии.
- Автоматическая инициализация таблиц SQLite при запуске.
- Интерактивная документация API на `/docs`.

## Чем отличаются два режима

1. **Распознавание изображения (`/analyze`)**. Приложение получает файл, запускает YOLOv8 и само считает три поддерживаемых категории. Результат возвращается в ответе и записывается в историю обнаружений.
2. **Запись метрик камеры (`/api/v1/metrics/with-photo`)**. Приложение сохраняет переданные клиентом значения и фотографию. Количество транспорта, скорость и загруженность в этом режиме не вычисляются моделью и не проверяются по содержимому фотографии.

Таким образом, проект объединяет компьютерное зрение для отдельных кадров и API для приёма уже рассчитанных показателей от внешней системы.

## Технологический стек

| Уровень | Технологии |
| --- | --- |
| Сервер и API | Python 3.10+, FastAPI, Uvicorn |
| Распознавание | Ultralytics YOLOv8n, модель COCO `yolov8n.pt` |
| Обработка изображений | OpenCV (`opencv-python-headless`), загрузка файлов через `python-multipart` |
| Хранение | SQLite, стандартный модуль `sqlite3` |
| Веб-интерфейс | HTML, CSS и JavaScript без отдельного frontend-фреймворка |
| Статические файлы | FastAPI StaticFiles |

## Быстрый запуск

Нужен Python 3.10 или новее. Команды выполняются из корня проекта.

### Linux и macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### Windows PowerShell

```powershell
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

После запуска:

- Веб-панель: <http://127.0.0.1:8000/>
- Swagger UI: <http://127.0.0.1:8000/docs>
- OpenAPI JSON: <http://127.0.0.1:8000/openapi.json>

Файл `yolov8n.pt` должен находиться в корне проекта. Для работы распознавания требуются установленные зависимости и доступная серверу модель; вычисление выполняется на CPU или доступном PyTorch-устройстве.

## API

Все маршруты доступны на том же адресе и порту, что и веб-панель.

| Метод и путь | Назначение | Успешный ответ |
| --- | --- | --- |
| `GET /` | Возвращает веб-панель | HTML-страница |
| `POST /analyze` | Распознаёт объекты на изображении из поля `file` | `traffic_count`, `details`, `filename` |
| `GET /detections/recent?limit=100` | Возвращает последние результаты распознавания | Объект с массивом `items` |
| `POST /api/v1/metrics/with-photo` | Сохраняет метрики формы и фото | HTTP 201, статус и `image_url` |
| `GET /api/v1/metrics/recent?limit=100` | Возвращает последние записи метрик | Массив записей |

### Распознавание изображения

`POST /analyze` принимает `multipart/form-data` с полем `file`. Поддерживаются расширения JPG, JPEG, PNG, BMP и GIF; максимальный размер файла — 50 МБ.

```bash
curl -X POST http://127.0.0.1:8000/analyze \
-F "file=@road.jpg"
```

Пример ответа:

```json
{
"traffic_count": 3,
"details": {
"cars": 2,
"buses": 0,
"trucks": 1
},
"filename": "road.jpg"
}
```


Список обнаружений можно получить так:

```bash
curl "http://127.0.0.1:8000/detections/recent?limit=100"
```


Параметр `limit` для этого маршрута должен быть от 1 до 1000.

### Сохранение метрик камеры

Маршрут принимает `multipart/form-data`: текстовые поля `camera_id`, `vehicle_count`, `average_speed`, `traffic_jam_level` и обязательный файл `file`.

```bash
curl -X POST http://127.0.0.1:8000/api/v1/metrics/with-photo \
-F "camera_id=camera-01" \
-F "vehicle_count=12" \
-F "average_speed=34.5" \
-F "traffic_jam_level=1" \
-F "file=@camera.jpg"
```

Фотография сохраняется в `static/uploads/`, а её URL и остальные значения записываются в базу. Уровни загруженности `0–3` используются интерфейсом как «свободно», «умеренно», «плотный поток» и «затор»; сервер принимает числовое значение без отдельной проверки этого диапазона.

Последние метрики:

```bash
curl "http://127.0.0.1:8000/api/v1/metrics/recent?limit=100"
```

## Данные и файлы

- `detections.sqlite3` хранит таблицы `detections` и `traffic_monitoring`; схема создаётся при импорте модуля базы данных во время старта приложения.
- Для каждого распознанного типа с ненулевым количеством создаётся отдельная запись с типом и количеством.
- Метрики камеры сохраняются отдельно от результатов YOLO.
- Временный файл, отправленный на `/analyze`, удаляется после обработки, в том числе при ошибке.
- Фотографии метрик остаются в `static/uploads/` и доступны по URL вида `/static/uploads/<имя-файла>`.
- Панель запрашивает последние 100 записей; отображаемые сводные числа рассчитываются по полученному списку, а не по полному архиву.

## Ограничения текущей версии

- Анализируется загруженное изображение; захвата видеопотока, обработки видео и подключения к камерам в реальном времени нет.
- Модель считает только легковые автомобили, автобусы и грузовики. Другие классы COCO игнорируются.
- Раздел метрик не рассчитывает скорость или уровень затора и не сверяет введённое количество с фотографией.
- Хранилище SQLite предназначено для локального запуска и небольших сценариев; серверной аутентификации и разграничения доступа в проекте нет.
- Загрузка фото метрик не использует ограничение размера и проверку типа файла, которые предусмотрены для `/analyze`.
